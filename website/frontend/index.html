How it works

  1. You add a slice. It stays in your browser until you press Analyze slice.
  2. The server converts it to RGB and resizes it to the models' input size with Lanczos resampling. Pixel values are passed through unscaled, the same as in the training project's test script.
  3. The classifier scores each class. The segmentation model produces a probability for every pixel, and pixels at 0.5 or above are marked.
  4. Grad-CAM shows where the classifier looked. Use the wipe handle to compare any view with the original.
